How it works

The same JavaScript middleware as Bananarama for Windows, kept alive on your phone by Termux.

You ask

Tap New image, share text to Termux, tap a widget, or type /image in Claude Code.

Middleware

A background service keeps server.js running on 127.0.0.1:7861 with a wake lock, and restarts it if it crashes.

Stream back

Gemini streams the image back in chunks, and they're put back together on the phone.

Gallery

Saved to Pictures/Nano, scanned into the Gallery, and shown in a notification.

Install

Four free apps from F-Droid, then one command. The Play Store Termux is outdated, so don't use it.

  1. Install Termux, Termux:API, Termux:Boot and, optionally, Termux:Widget. Open Termux:Boot once.

  2. Open Termux and paste:

    curl -fsSL https://raw.githubusercontent.com/GunGreenEyes/Bananarama-Android/main/install.sh | bash

  3. Allow storage access, then paste a Gemini API key from AI Studio when asked. Image models need billing on the key's Google Cloud project.

To update, run the same command again. To remove it, run bananarama uninstall; your settings and images are kept.

Galaxy S25: keep it running

One UI puts background apps to sleep. Do these once.

WhereSet
Settings → Battery → Background usage limitsAdd Termux, Termux:API and Termux:Boot to Never sleeping apps
Settings → Apps → Termux → BatteryUnrestricted
NotificationsAllow them for Termux and Termux:API
Developer options (optional)Disable child process restrictions, so Android 14+ doesn't kill the middleware
