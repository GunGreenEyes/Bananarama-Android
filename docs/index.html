How it works

A real Android app. Your key stays on your phone and goes only to Google.

You pick text

Select it in Claude (or any app) and tap Make image, or share it to Bananarama.

Confirm

A small sheet shows the description and options. Add 16:9, 2K or pro, then tap Make it.

Install

No app store and no extra apps. About a minute.

  1. On your phone, tap Download Bananarama.apk, then open it and tap Install. The first time, Android asks you to allow installs from your browser; allow it once.

  2. Open Bananarama. Tap Get a free key from Google, copy the key from AI Studio, paste it, and Bananarama checks it. Image models need billing on the key's Google Cloud project.

  3. Allow notifications, and you're done. Try it: select some text in Claude and tap Make image.

To update, install a newer Bananarama.apk over the old one. For Claude Code in Termux, see the README.
